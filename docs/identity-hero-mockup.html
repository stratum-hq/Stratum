Five lines to a working hierarchy

Connect a pool, create tenants with parents, and config resolves up the tree. The one thing lit in the accent color is the payoff: the resolved value.

import { Stratum } from "@stratum-hq/lib"; const stratum = new Stratum({ pool }); const root = await stratum.createTenant({ slug: "acmesec" }); const msp = await stratum.createTenant({ parent_id: root.id }); await stratum.setConfig(root.id, "max_users", { value: 1000 }); const cfg = await stratum.resolveConfig(msp.id); // → max_users: 1000 inherited from "acmesec"
